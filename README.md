# 凿一面墙：科技安全网页 PPT

本项目以“中国科技安全”为主题，采用网页 PPT 的形式呈现，共 20 页，包含主题演示页面、动效和配套讲稿。

## 项目内容
 
- `index.html`：网页 PPT 主文件
- `jianggao.txt`：展示讲稿参考
- `images/`：演示所用视觉素材
- `assets/`：页面运行所需资源文件
- `NOTICE.md`：代码与素材的许可边界

## 运行方式
在线预览：[A1yusha.github.io/keji-anquan-ppt](https://A1yusha.github.io/keji-anquan-ppt/)

也可以下载仓库后，直接使用浏览器打开 `index.html`。
演示时可使用键盘方向键进行翻页。
